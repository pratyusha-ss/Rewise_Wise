ReviseWise is a Python project I created for my Year 12 programming project.
I wanted to make a revision planner that helps students organise their topics and decide what to revise first.

Features
* Add, view and edit topics.
* Calculate revision priorities.
* Search and sort topics.
* Save data using JSON files.
* Check inputs to prevent errors.
* Use a graphical user interface.

ReviseWise calculates a priority score out of 10 using confidence, difficulty, exam dates and when the topic was last revised.

Used:
* Python
* Tkinter
* JSON

What I Learned:
This project helped me improve my Python skills and learn more about file handling, functions, dictionaries, sorting, input validation and creating a GUI.
I also learned how to bring different features together to create a working program.
